# 6차시. 테마별로 골라 보는 지도

⏱ 25분 (개념 6 · 실습 15 · 정리 4) · 결과물: **테마별 장소 탐색 지도**

## 학습 목표
- 카테고리 필터와 검색이 **지도와 목록에 동시에** 적용되는 구조를 이해한다.
- 장소 카드와 상세 정보 화면을 확인·수정한다.
- 결과 없음·초기화 같은 "빈 상태" UX를 챙긴다.

## 선수 준비사항
- 5차시 지도. 코드: `lib/data/filter.ts`, `components/places/*`, `components/AtlasApp.tsx`, `data/categories.json`

## 강사 설명 핵심 개념
1. **하나의 목록, 두 개의 화면**: `filterPlaces()` 결과 한 배열을 지도와 목록이 함께 쓴다 → 항상 일치.
2. **카테고리 = 데이터**: 칩은 `data/categories.json` 에서 생성된다. 코드에 하드코딩하지 않는다(추가·이름변경은 JSON만).
3. **검색**: 이름(한/영)·태그·주소에서 대소문자 무시 부분일치.
4. **상태 4종**: 결과 있음 / 결과 없음 / 필터 적용 중(초기화 버튼) / 로딩.
5. 지도 ↔ 목록 연동: 마커 클릭 → 목록 항목 활성화·스크롤, 목록 클릭 → 지도 이동·팝업.

## 단계별 실습
1. `data/categories.json` 에서 카테고리 이름을 바꾸고(`labelKo`) 화면 칩이 바뀌는지 확인.
2. 카테고리 1개를 추가(`id`, `labelKo`, `labelEn`, `color`, `icon`) → `places.csv` 의 일부 장소 `category` 를 새 id로 변경 → `npm run validate:data`.
   - icon 은 `utensils|coffee|trees|landmark|camera` 중 하나(없으면 핀 아이콘).
3. 칩 클릭 → 마커 수와 목록 수가 같이 줄어드는지, "N곳" 표시 확인.
4. 검색창에 "국수", 그 다음 "zzzz" 입력 → 결과 없음 안내 → **필터 초기화**.
5. 마커를 누르거나 목록 카드를 눌러 **같은 장소 상세**(데스크톱: 왼쪽 패널, 모바일: 바텀시트)가 열리는지, 상세에서 **외부 길찾기**·**이 장소가 포함된 코스** 확인. **← 목록으로** 를 누르면 방금 보던 카드로 돌아옵니다.

## 예상 결과물
테마 칩 + 검색 + 목록 + 상세 카드가 지도와 연동된 화면.

## 정상 작동 확인 방법
- 샘플 데이터 기준: "카페" 선택 시 "7곳", 마커 7개. (완성본 실데이터는 카페 374곳 → 세부 종류 칩: 카페·빵/도넛·아이스크림/빙수)
- "zzzz" 검색 시 안내 문구, **필터 초기화** 로 복귀.
- `npm run test:e2e -- -g "필터"` 통과.

## 초보자가 겪을 수 있는 오류 → 해결
| 증상 | 해결 |
|---|---|
| 새 카테고리 칩이 안 보임 | `categories.json` JSON 문법(쉼표) 확인, `validate:data` |
| `존재하지 않는 category: xxx` | CSV 의 category 철자를 JSON id 와 맞춤 |
| 칩은 바뀌는데 마커가 안 줄어듦 | 지도에 전달하는 배열이 필터 결과인지 확인(`mapPlaces`) |
| 모바일에서 칩이 안 보임 | 지도 위쪽에 가로 스크롤로 표시됨(옆으로 밀기) |

## 학습 정리
데이터(JSON/CSV) → 필터 함수 → 지도·목록. 필터는 한 곳, 화면은 둘.
