# 2차시. 우리 동네에서 나만 아는 주제 찾기

⏱ 25분 (개념 7 · 실습 14 · 정리 4) · 결과물: **여행 지도 기획안**

## 학습 목표
- 지도에 담을 **지역·테마·대상 방문객**을 정한다.
- 서비스의 핵심 가치를 한 줄로 정의한다.
- 테마를 `categories.json` 형태(카테고리)와 코스 3종으로 바꾼다.

## 선수 준비사항
- 1차시 서비스 한 문장.
- 내 동네에서 자주 가는 곳 목록(휴대폰 사진첩·지도 즐겨찾기).

## 강사 설명 핵심 개념
1. **지역 범위**: 걸어서 2~3km 이내(코스를 걸을 수 있어야 함).
2. **카테고리 vs 테마**: 카테고리 = 필터 칩(맛집·카페…), 테마 = 코스의 분위기(감성 골목·역사 …). 프로젝트의 `data/categories.json` 에 둘 다 있다.
3. **방문객 유형**: (예) 당일 여행객 / 외국인 / 가족 / 혼자 걷는 사람. 유형이 정해지면 코스가 정해진다.
4. **나만의 관점**: "검색하면 나오는 곳" 이 아니라 *내가 직접 가 본* 곳.

## 단계별 실습
1. 지역 정하기: 동네 이름 + 지도 중심 좌표(구글맵 우클릭 → 좌표 복사).
2. 카테고리 3~5개, 코스 테마 3개 정하기.
3. 방문객 1유형을 골라 **페르소나 카드** 작성(이름·나이·목적·불편함).
4. 핵심 가치 1줄: "○○ 방문객이 ○○ 걱정 없이 ○○을 즐긴다."
5. 아래 기획안 양식을 채운다.

```markdown
# 여행 지도 기획안
- 서비스 한 문장:
- 지역/지도 중심 좌표(위도, 경도):
- 대상 방문객(페르소나):
- 카테고리(3~5):
- 코스 3종(제목/분위기/대략 몇 곳):
- 핵심 가치 한 줄:
- 직접 확인한 장소 후보 10곳:
```

## AI 코딩 도구용 실습 프롬프트
```text
아래는 제 여행 지도 기획안입니다. (붙여넣기)
1) 빠진 항목이나 모순을 찾아 주세요.
2) 카테고리 id 후보를 영문 소문자-하이픈 형식으로 제안해 주세요(예: cafe, nature).
3) 코스 3종의 영문 제목 후보를 제안해 주세요.
실제로 존재하는지 확인할 수 없는 장소를 추가하거나 지어내지 마세요. 제가 준 후보 안에서만 정리해 주세요.
```

## 예상 결과물
`planning.md` 기획안 1장.

## 정상 작동 확인 방법
- 코스 3종이 서로 다른 테마이고, 장소 후보가 코스마다 5곳 이상 연결된다.
- 지도 중심 좌표가 `config/site.ts` 의 `region.center`(**[경도, 위도]** 순서) 형식으로 옮길 수 있다.

## 초보자가 겪을 수 있는 오류 → 해결
| 오류 | 해결 |
|---|---|
| 위도·경도를 반대로 적음 | 한국은 위도 33~38, 경도 124~132. 설정 파일은 `[경도, 위도]`, CSV는 열 이름으로 구분 |
| 지역이 너무 넓음 | 도보 코스가 안 되면 동 단위로 축소 |
| 테마가 겹침 | 방문객이 "오늘 뭐 할지"로 구분되게 다시 나눔 |

## 학습 정리
지역 → 테마 → 방문객 → 가치 순으로 좁히면 코스와 필터가 자연스럽게 나온다.
