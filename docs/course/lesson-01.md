# 1차시. 지역 크리에이터에게 지도가 왜 무기가 될까?

⏱ 25분 (개념 8 · 시연/실습 12 · 정리 5) · 결과물: **나의 서비스 한 문장**

## 학습 목표
- 글·영상 게시물과 **지도형 콘텐츠**의 차이를 설명한다.
- 완성 서비스(LOCAL ATLAS)의 기능과 최종 산출물을 안다.
- 내가 만들 서비스를 한 문장으로 쓴다.

## 선수 준비사항
- 노트북, 인터넷, 크롬 브라우저. (설치는 아직 필요 없음)
- 강사 제공 데모 주소 또는 로컬 실행 화면 (`npm run dev`).

## 강사 설명 핵심 개념
1. **흩어진 정보 → 하나의 자산.** SNS 글은 흘러가지만, 공개 URL 지도는 **남는다**. 링크·QR·프로필에 붙여 계속 쓴다.
2. **위치 기반 큐레이션.** 장소 + 테마 + 코스 = 방문객이 "그대로 따라 하는" 콘텐츠.
3. **AI는 도구.** 이 강의에서 AI는 *코드를 대신 쓰는 조수*이다. 서비스 안에 "AI가 코스를 추천"하는 기능은 만들지 않는다. 내가 발굴한 장소·코스가 가치다.
4. 수익 구조가 아니라 **"지도가 왜 내 자산이 되는가"** 에 집중한다.

## 단계별 실습
1. (강사) 완성 서비스 시연: 지도 → 테마 필터 → 마커 탭 → 코스(번호·점선) → EN 전환 → 공유·QR → 휴대폰으로 QR 스캔.
2. (수강생) 데모에서 마음에 든 기능 3가지, "우리 동네에 있으면 좋겠다" 싶은 것 1가지를 메모.
3. 12차시 로드맵(`docs/COURSE_INDEX.md`)을 보고 최종 산출물 체크리스트를 확인한다.
4. **서비스 한 문장** 쓰기. 형식:
   > "(누구)가 (어디)에서 (무엇)을 (어떻게) 즐기도록 돕는 (테마) 지도"
   > 예) "서울 성수동을 처음 오는 외국인이 하루 동안 걷기 좋은 카페·공방 코스를 따라갈 수 있는 지도"

## AI 코딩 도구용 실습 프롬프트
이번 차시는 코드를 만들지 않습니다. 한 문장을 다듬을 때만 사용하세요.
```text
내 서비스 한 문장입니다: "<내가 쓴 문장>"
방문객 입장에서 헷갈리는 부분 3가지를 질문 형태로 알려 주고, 더 구체적인 버전 2개를 제안해 주세요.
단, 존재하지 않는 장소나 통계를 지어내지 마세요.
```

## 예상 결과물
`my-service.md` (또는 메모장)에 서비스 한 문장 1개.

## 정상 작동 확인 방법
- 문장에 **누구 / 어디 / 무엇 / 테마** 4요소가 모두 있다.
- 데모 주소가 열리고 지도에 마커가 보인다.

## 초보자가 겪을 수 있는 오류 → 해결
| 오류 | 해결 |
|---|---|
| 데모 지도가 베이지색 빈 화면 | 타일 로딩 중. 5~10초 기다리거나 새로고침 |
| 한 문장이 너무 넓다("전국 맛집 지도") | **한 동네·한 테마**로 좁힌다 |
| 휴대폰에서 QR이 안 열림 | 강사 PC의 `localhost` 주소 QR은 열리지 않음 → 공개 주소 사용(11차시에서 해결) |

## 학습 정리
- 지도 = 흩어진 콘텐츠를 모으는 **공개 URL 자산**.
- AI는 개발 보조, 가치는 내 동네 지식.
- 최종 산출물: 장소 30곳 · 코스 3종 · 모바일 · 다국어 · 공개 URL·QR.
