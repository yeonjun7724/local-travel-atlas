# 운영 가이드

## 1. 데이터 수정 (CSV)

1. `data/places.csv` 를 엑셀/구글 시트/VS Code 로 연다.
2. 장소를 추가·수정한다. 새 장소는 **마지막 줄에 한 줄 추가**, `id` 는 새로 만든 고유 영문 값.
3. **CSV UTF-8** 로 저장한다.
4. `npm run validate:data` → `✅` 확인.
5. 로컬에서 `npm run dev` 로 눈으로 확인.
6. `git add data && git commit -m "…" && git push` → Vercel 자동 재배포 확인.

## 1-1. 실데이터 정기 갱신 (분기 1회 권장)

1. `.venv/Scripts/python scripts/data-pipeline/fetch_places.py` — 진흥공단 상가정보(분기 갱신)·OSM 변경 반영
2. `.venv/Scripts/python scripts/data-pipeline/build_routes.py` — 도보 경로 재계산
3. `npm run validate:data` → `git diff --stat data/` 로 변화량 확인 → 커밋·푸시
4. 진흥공단 키는 `.env.local` 에만 두고 Vercel 에는 등록하지 않습니다(빌드에 불필요).

## 2. 장소 추가 체크리스트

- [ ] 좌표를 지도에서 **직접 확인**(주소와 마커가 맞는지)
- [ ] `source`(출처: 직접 답사/공공데이터 이름·URL)와 `license`(이용조건) 기록
- [ ] 사진은 **직접 촬영·허가된 것**만 (`public/images/`, `imageUrl=/images/…`)
- [ ] `updatedAt` 에 확인한 날짜
- [ ] 직접 추가한 장소는 `isSample=false`, 출처 링크(`sourceUrl`)를 함께 기록
- [ ] 영어 이름·설명 검토(자동 번역은 지명·상호명을 틀리기 쉬움). 비워 두면 한국어로 표시됨

## 3. 코스 변경

`data/routes.json` 에서 `placeIds` 배열의 순서 = 방문 순서. 장소를 빼거나 순서를 바꾼 뒤 `npm run validate:data`. 코스를 늘리려면 객체를 하나 복사해 `routeId` 를 새로 지정한다(영문 소문자·숫자·하이픈).

## 4. 재배포

`git push` 가 곧 재배포. 환경변수만 바꿨다면 Vercel → Deployments → ⋯ → **Redeploy**. 이전 버전으로 돌리려면 정상이던 배포의 **Promote to Production**(또는 Instant Rollback).

## 5. 지도 서비스 점검 (월 1회)

- [ ] 공개 URL에서 지도 타일이 뜨는가 (OpenFreeMap 상태: <https://openfreemap.org>)
- [ ] 지도 오른쪽 아래 **출처 표시**가 보이는가 (삭제 금지)
- [ ] OpenFreeMap 이용 안내(공개 인스턴스 사용 조건·후원 안내)가 바뀌지 않았는지 확인. 트래픽이 많아지면 자체 호스팅·후원·유료 타일 제공자를 검토
- [ ] `npm outdated` 로 maplibre-gl·next 업데이트 확인 (업데이트 후 `npm run build && npm test`)

## 6. API 사용량·비용 점검 (키를 쓴 경우)

- OpenRouteService 대시보드에서 **일/분당 한도와 사용량** 확인. 무료 한도는 서비스 정책에 따라 바뀌므로 [공식 요금·한도 페이지](https://openrouteservice.org/plans/)를 직접 확인한다. (이 저장소는 한도 수치를 보증하지 않음)
- 서버는 **같은 코스·이동수단 결과를 1시간 캐시**하고 인스턴스당 분당 20회로 제한한다. 서버리스는 인스턴스가 여러 개일 수 있어 완전한 상한이 아니다 → 사용량 급증이 보이면 ORS 대시보드에서 키를 폐기/재발급하고 Vercel 환경변수를 갱신.
- 비밀 키 유출이 의심되면: ① ORS 에서 키 삭제 ② 새 키 발급 ③ Vercel 환경변수 교체 ④ Redeploy.
- 유료 플랜 전환·결제는 본인이 직접 결정·승인한다.

## 7. 방문 통계 확인

- Vercel 프로젝트 → **Analytics**: 방문자 수·페이지 조회·유입 경로(플랜별 제공 범위 상이).
- ⚠️ 이 데이터는 **페이지 조회**이며 **코스별 인기도가 아니다.** 이 앱은 코스·장소 선택이 URL 쿼리(`?route=`)로만 바뀌므로, 쿼리별 조회가 대시보드에 구분되어 나오는지는 플랜·설정에 따라 다르다 → **확인 전에는 인기 코스라고 결론 내리지 않는다.**
- 코스 인기도를 정확히 보려면 "코스 선택" 이벤트를 수집·집계해야 한다(Vercel 커스텀 이벤트는 플랜 제한 가능 → 선택 확장, PRD §8). 현재 코드에는 구현되어 있지 않다.
- 수치를 직접 확인하지 않은 채 보고서에 쓰지 않는다.

## 8. 라이선스 확인 (분기 1회)

- [ ] `places.csv` 의 `source`/`license` 가 비어 있지 않다(검증이 강제)
- [ ] 공공데이터는 이용허락범위(상업 이용·출처표시·변경 가능 여부) 재확인
- [ ] 상업적 이용 가능 여부가 **불명확**한 자료는 `license` 에 "상업적 이용 확인 필요" 로 명시
- [ ] 사진·리뷰를 외부 서비스에서 가져오지 않았다
- [ ] 지도 출처(OpenFreeMap/OpenMapTiles/OSM) 표시 유지
