## 2. 단위 테스트 (Vitest) — 34/34 통과

- 실제 데이터: 30곳 이상, 코스 3종·각 5~8곳, 참조 유효, 좌표 범위, 태그 분리, 한글 정상
- 검증 규칙이 **잘못된 데이터를 잡아내는지**: id 중복, 위도 범위, 없는 category, 필수 값 누락, `javascript:` URL, 깨진 문자(U+FFFD), 필수 열 누락, 코스 참조 id 없음/중복, JSON 문법 오류, 엑셀 BOM 허용
- 공유 URL 생성·파싱·잘못된 값 무시, 로컬 주소 판별
- 필터·검색, 다국어 키 일치·영어 폴백·변수 치환, bounds
- OpenRouteService 클라이언트(**mock fetch**): 정상 파싱, 프로필·키 헤더, 429/500/형식 오류/네트워크 실패

개발 중 실제로 발견·수정된 문제: ① 샘플 CSV 한 행의 설명 누락(검증기가 탐지) ② 테스트 타입 불일치(빌드 타입체크가 탐지).

## 3. 브라우저 E2E (Playwright)

**UX/UI 리디자인 이후(2026-10-20): 80/80 통과** (desktop 1280 · mobile Pixel 7 · with-key). 추가된 검증:
- 5개 뷰포트(375/430/768/1280/1920) 렌더·가로 스크롤 없음·컨트롤이 시트·출처 표시를 가리지 않음 + 스크린샷(`docs/screenshots/`)
- 마커/카드 → 동일 상세 패널, 뒤로 가기 시 카드 포커스 복원, 상세→코스 이동, Esc·`/` 키보드 흐름
- 검색+필터 교집합, 검색어 지우기/Esc, 바텀시트 탭 순환·**드래그 스냅**·마커 탭 시 자동 열림
- 위치 성공/거부 토스트, 오프라인 배너·복귀 안내, `prefers-reduced-motion`
- 영어 전환 시 새 UI 문구(검색·칩·컨트롤·상세) 번역
- **axe-core 자동 접근성 검사**(첫 화면·상세·코스·공유 대화상자+EN): serious/critical 위반 0 (캔버스 제외, 수동 점검 대체 불가)
- 색 대비를 직접 계산(AA 4.5:1 이상 전부 충족, 최저 4.54)

이전(리디자인 전) 기록: 41/41 통과.

개발 중 E2E 로 발견·수정한 실제 결함

1. **지도 배경(타일) 미표시 + 콘솔 `Worker failed to load`** — Next(Turbopack) 번들에서 MapLibre 워커 경로가 깨짐 → 워커 파일을 `public/maplibre/` 로 복사하고 `setWorkerUrl` 사용. 수정 후 타일 응답 200, 도로·지명 렌더 확인(스크린샷).
2. 타일 하나의 오류를 "지도 실패"로 오인 → 스타일 URL 오류/20초 미준비일 때만 실패 처리, 레이어는 `style.load` 에서 추가.
3. 데스크톱 테마 칩 중복 렌더 → 수정.
4. 모바일에서 코스의 6·7번 마커가 바텀시트에 가려짐 → 하단 여백 비율 조정(스크린샷으로 7개 모두 보임 확인).
5. 검색 결과 1곳일 때 `fitBounds` 위치 불안정 → 단일 지점은 `easeTo` 로 처리.
